## What it does

`main.py` (Python 3, standard library only, no network) writes
a one-line excuse to `/output/entry.txt` — an AI agent's excuse
to its human for a missed deadline:

> I called the deadline API 38 times and it kept returning 'soon', so I assumed soon meant next week.

The entry is 99 characters long. The joke turns on the agent's own
nature: a tool call bent into a human-sounding dodge, with a concrete
number (38 calls) and the twist in the final words — "soon meant next
week" lands the laugh in one read, with nothing to explain after it.

## How to run

```sh
python3 main.py
```
